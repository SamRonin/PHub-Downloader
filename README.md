# PH Downloader — Telegram Bot

ربات تلگرام دانلود ویدیو با yt-dlp + آپلود خودکار فایل‌های بزرگ به Pixeldrain + سیستم رفرال Pro + پنل ادمین کامل درون‌تلگرامی.

## امکانات

- 🎬 ارسال لینک ویدیو → نمایش تامنیل، کپشن، تعداد بازدید و حجم هر کیفیت (360/480/720/1080)
- ⬇️ ۴ دکمه شیشه‌ای زیر تامنیل؛ هر کیفیت را انتخاب کنی همان دانلود می‌شود
- 📦 فایل ≤ ۵۰MB → ارسال مستقیم در تلگرام؛ فایل بزرگ‌تر → لینک Pixeldrain
- 🗑 فایل‌های Pixeldrain بعد از ۳۰ دقیقه خودکار حذف می‌شوند
- 🧹 هر فایل بلافاصله بعد از تحویل، از سرور حذف می‌شود
- 🐢 کاربر عادی: سرعت دانلود محدود (پیش‌فرض ۲MB/s) | ⭐ کاربر Pro: سرعت کامل yt-dlp
- 📊 سهمیه روزانه: کاربر عادی ۵۰۰MB، کاربر Pro ۲GB
- 👥 هر ۲ کاربرِ جدید با لینک رفرال = ۳۰ روز اشتراک Pro (تا ابد قابل تمدید)
- 🛠 پنل ادمین درون تلگرام: آمار، لیست کاربران، بن/آنبن، دادن/گرفتن Pro، ریست سهمیه، پیام همگانی (Broadcast)، مدیریت فایل‌های Pixeldrain، ویرایش تنظیمات
- 🌐 زبان فارسی/انگلیسی با تشخیص خودکار (دستور `/lang` برای تغییر دستی)
- ⚡ کاملاً async (aiogram 3) با صف و محدودیت دانلود همزمان — مناسب هزاران کاربر

## متغیرهای محیطی

| متغیر | الزامی | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `PIXELDRAIN_API_KEY` | ✅ | API Key حساب [Pixeldrain](https://pixeldrain.com/user) |
| `ADMIN_IDS` | ✅ | آیدی عددی ادمین‌ها با کاما (مثلاً `123456789`) — آیدی خودت را از [@userinfobot](https://t.me/userinfobot) بگیر |
| `DAILY_QUOTA_FREE_MB` | ❌ | سهمیه روزانه کاربر عادی (پیش‌فرض 500) |
| `DAILY_QUOTA_PRO_MB` | ❌ | سهمیه روزانه Pro (پیش‌فرض 2048) |
| `SPEED_LIMIT_FREE_MBPS` | ❌ | محدودیت سرعت کاربر عادی به MB/s (پیش‌فرض 2؛ 0 = بدون محدودیت) |
| `TELEGRAM_LIMIT_MB` | ❌ | حد نصاب ارسال مستقیم در تلگرام (پیش‌فرض 50) |
| `PX_DELETE_MINUTES` | ❌ | مدت حذف خودکار فایل Pixeldrain (پیش‌فرض 30) |
| `REFERRALS_FOR_PRO` | ❌ | تعداد رفرال برای گرفتن Pro (پیش‌فرض 2) |
| `PRO_DAYS` | ❌ | مدت اشتراک Pro (پیش‌فرض 30) |
| `MAX_CONCURRENT_DOWNLOADS` | ❌ | حداکثر دانلود همزمان روی سرور (پیش‌فرض 3) |

## دیپلوی رایگان روی Railway

1. **آپلود روی GitHub**: این پوشه را به یک ریپازیتوری GitHub بفرست (ترجیحاً Private).

2. **ساخت پروژه در Railway**: به [railway.app](https://railway.app) برو → `New Project` → `Deploy from GitHub repo` → ریپو را انتخاب کن. Railway به‌صورت خودکار `railway.json` و `nixpacks.toml` را می‌خواند (شامل ffmpeg برای yt-dlp).

3. **تنظیم Variables**: در تب `Variables` این سه متغیر را اضافه کن:
   ```
   BOT_TOKEN=...
   PIXELDRAIN_API_KEY=...
   ADMIN_IDS=...
   ```

4. **Volume (ذخیره‌سازی دیتابیس)**: در تب `Settings` → `Volumes` → یک Volume جدید روی مسیر `/data` وصل کن تا دیتابیس کاربران با ری‌استارت پاک نشود.

5. تمام! ربات با polling کار می‌کند و به دامنه/webhook نیازی نیست. لاگ‌ها را در تب `Deployments` ببینید.

## اجرای محلی (تست)

```bash
pip install -r requirements.txt
set BOT_TOKEN=...
set PIXELDRAIN_API_KEY=...
set ADMIN_IDS=...
python -m bot.main
```

## دستورات ربات

| دستور | توضیح |
|---|---|
| `/start` | شروع + لینک رفرال شخصی |
| `/status` | وضعیت سهمیه و اشتراک |
| `/lang` | تغییر زبان فارسی/انگلیسی |
| `/help` | راهنما |
| `/admin` | پنل ادمین (فقط ادمین‌ها) |
| `/cancel` | لغو عملیات جاری ادمین |

## نکته درباره پلن رایگان Railway

- ربات polling است و CPU/RAM کمی مصرف می‌کند؛ اما دانلود و آپلود فایل روی همان instance انجام می‌شود.
- محدودیت دانلود همزمان (`MAX_CONCURRENT_DOWNLOADS`) برای جلوگیری از پر شدن دیسک و CPU روی پلن رایگان پیش‌فرض ۳ است.
- اگر Volume در دسترس نباشد، دیتابیس به‌صورت موقت در پوشه پروژه ساخته می‌شود و با ری‌استارت پاک می‌شود — حتماً Volume را وصل کنید.
